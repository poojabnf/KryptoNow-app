# KryptoNow Browser Extension

## Install in Chrome / Brave / Edge

1. Go to: chrome://extensions
2. Enable "Developer mode" (top right)
3. Click "Load unpacked"
4. Select this "extension" folder
5. KryptoNow icon appears in toolbar!

## First Time Setup

1. Click the KryptoNow icon
2. Click "Import Wallet"
3. Enter wallet address + private key
4. Select your chain
5. Done!
